## ⚡ Engineering Highlights

- 🏗️ **Mobile Architecture & Ownership** — Sole mobile engineer on a ~110-screen production app with 10,000+ registered advocates, owning mobile architecture, release engineering, and Play Store submission end to end alongside a 3-person backend team.
- 🔐 **Two-Layer Access Control** — Role-based permissions resolved against subscription-tier entitlements, designed so a malformed plan response degrades gracefully instead of stripping paying subscribers of purchased features.
- 🔄 **Resilient Auth Layer** — Eliminated unintended logouts on unstable networks with a centralized fetch layer that collapses concurrent token refreshes into a single in-flight request, guards against retry loops, and tolerates offline 401s.
- 💳 **In-App Purchases** — App-wide StoreKit provider so auto-renewals, "Ask to Buy" approvals, and post-outage redeliveries are never dropped — backing a 4-tier subscription group and consumable wallet top-ups with server-side receipt verification.
- 📝 **Document Sync Engine** — Snapshot-diffing sync between concurrent web and mobile editors with debounced batching and 413-safe chunking, surfacing a visible failure state instead of failing silently.
- 🌊 **Token-by-Token AI Streaming** — Replaced React Native's buffering fetch with SSE over `expo/fetch`; extended the pattern to WebSocket dictation and Socket.IO live transcription.
- 🚢 **Release Engineering** — Cut hotfix turnaround from a full store review cycle to a same-day push via EAS Update OTA; authored 7 Expo config plugins and maintain 4 EAS build profiles across Android and iOS.
- 🛡️ **Privacy & Compliance** — Network-layer AI-disclosure consent gate that blocks third-party AI requests before any user content leaves the device, satisfying Apple's App Store disclosure requirements.

## 🌟 Project Spotlight

### 📡 rn-network-quality
Open-source React Native **New Architecture TurboModule** exposing live bandwidth and link-quality signals — replacing the binary online/offline flag most RN apps rely on.
- **Native Bridging:** Android `NetworkCapabilities` + iOS `NWPathMonitor` behind a codegen'd TypeScript spec, implemented in Kotlin and Swift.
- **Production-Ready Packaging:** Runnable example app, GitHub Actions CI, and semantic-versioned npm releases.

### 🏠 Tenet
Rental and tenancy management app for independent landlords · React Native (Expo), TypeScript, Node.js, MongoDB.
- **Offline-First Ledger:** SQLite-backed rent ledger with an outbox sync queue — on-site entries reconcile on reconnect without double-posting a payment.
- **Multi-Role Codebase:** One app serving landlord and tenant roles via per-role navigation trees and server-driven entitlement checks.
- **Landlord Tooling:** Multi-property portfolios, lease document storage, auto-generated rent schedules, UPI collection with reminders, and maintenance-request threads.
